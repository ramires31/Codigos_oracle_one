# Iniciante em Programação G8 - ONE

## 🚀 Sobre o Projeto
O **Iniciante em Programação G8 - ONE** é o caminho das pedras para entrar no universo da programação e começar a criar sites utilizando as linguagens populares **HTML, CSS e JavaScript**. Este projeto é ideal para quem deseja dar os primeiros passos no desenvolvimento web e entender os conceitos fundamentais dessas tecnologias.

## 🛠 Tecnologias Utilizadas
- **HTML**: Estruturação do conteúdo da página.
- **CSS**: Estilização e layout responsivo.
- **JavaScript**: Interatividade e dinamismo no site.

## 📌 Objetivos
- Compreender os fundamentos do **HTML, CSS e JavaScript**.
- Desenvolver páginas web responsivas e interativas.
- Praticar conceitos essenciais do desenvolvimento front-end.

## 📂 Estrutura do Projeto
O projeto está organizado da seguinte maneira:
```
📁 iniciante-programacao-g8
│── 📄 index.html  # Página principal
│── 📄 style.css   # Estilos da página
│── 📄 script.js   # Código JavaScript
└── 📂 assets      # Imagens e outros arquivos
```

## 📖 Como Usar
1. Clone este repositório:
   ```bash
   git clone https://github.com/seu-usuario/iniciante-programacao-g8.git
   ```
2. Abra o arquivo `index.html` no navegador.
3. Edite os arquivos conforme necessário para personalizar seu aprendizado.
